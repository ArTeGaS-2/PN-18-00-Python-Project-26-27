Навчальний проєкт першого року IT-FRIENDS. Працюємо з даними замовлення й методами класу `Order`.

| Файл | Зміст |
|---|---|
| `order.py` | Дані замовлення, методи вибору розміру, показу меню та вибору наповнювачів |
| `main.py` | Створює `Order` і запускає вибір наповнювачів |
| `Плани.txt` | Ідеї подальших доповнень піцерії |

Потрібен Python 3, сторонні пакети не потрібні:

```console
python main.py
```

Стан після заняття 26.10.2026: вкладена функція перевіряє назву без урахування регістру та наявність наповнювача. Символ `-` завершує цикл, після чого виводиться підсумок. У словнику дані мають порядок `[кількість, ціна]`.

Збережено навчальний стан коду: умова `<=` дозволяє додати шосту назву при `max_topings_count = 5`; запас після додавання не зменшується. Вибір розміру та показ меню залишаються методами класу, але поточний `main.py` їх не викликає.
