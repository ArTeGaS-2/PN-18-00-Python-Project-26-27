# PizzaShop — ПН-18-00

Навчальний проєкт IT-FRIENDS 2026–2027, Python, перший рік.

Програма в терміналі запитує розмір піци та п’ять наповнювачів, зберігає відповіді у списку і показує замовлення двома способами. Використовуємо `input`, `print`, змінні, списки, `append` і цикли `for`.

Потрібен Python 3, сторонні пакети не потрібні. У папці проєкту виконайте:

```sh
python main.py
```

Після кожної відповіді натискайте Enter. Поточна версія зберігає всі п’ять відповідей, зокрема знак `-`; автоматичного пропускання наповнювачів ще немає. Файл `Плани.txt` містить ідеї подальших доповнень.
